## Full Summary

This comprehensive dataset artifact provides 800 synthetic stationary time series trials generated with varying sequence lengths (T=10, 20, 50, 100) and additive Gaussian noise variance levels (sigma^2 = 0.1, 0.5, 1.0, 2.0). Each trial includes the raw time series array, ground truth mean, noise variance, trial ID, and length. Structured in standardized JSON format with full, mini, and preview variants to rigorously evaluate moving average forecasting performance relative to naive last-value forecasting across diverse noise conditions and sample sizes.
